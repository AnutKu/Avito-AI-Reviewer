# Avito AI Reviewer — единый кабинет

Рабочий прототип единого кабинета для студента, ревьюера и методиста. Core API и данные работают на FastAPI + PostgreSQL, интерфейс — Vue 3. AI-review и Rubric CI пока детерминированно замоканы, но пишут результат в те же сущности и отдают те же HTTP-контракты, которые сможет использовать настоящий воркер.

## Запуск

```bash
cp .env.example .env
docker compose up --build
```

После запуска:

- кабинет: <http://localhost:3000>;
- OpenAPI: <http://localhost:8000/docs>;
- healthcheck: <http://localhost:8000/health>.

Если порт занят, его можно переопределить без изменения файлов:

```bash
UI_PORT=3001 docker compose up --build
```

На стартовом экране есть демо-вход для каждой роли. База заполняется учебным курсом, рубрикой, работами в разных статусах, ревью, сигналами и уведомлениями. Данные создаются только в пустой БД.

## Что реализовано

- настоящий JWT и серверный RBAC;
- ролевой кабинет со всеми экранами проектного решения;
- сдача GitHub-ссылки, неизменяемый снапшот и автомат статусов;
- объяснимое распределение по специализации и загрузке с подтверждением методиста;
- очередь и рабочее место ревьюера;
- принятие, изменение и отклонение каждого AI-вывода;
- отдельный AI-use/understanding signal, недоступный студенту;
- подтверждаемый человеком блиц-опрос и публикация результата;
- неизменяемые версии рубрик, настройки курса и демо-аналитика;
- in-app уведомления и фиче-флаги.

## Структура

```text
api/   FastAPI, core-домен, PostgreSQL, mock feature contracts
ui/    Vue 3, ролевые feature-модули, nginx
```

AI worker, LLM gateway и Telegram не входят в этот этап. Их места зафиксированы контрактами и фиче-флагами; интерфейс явно помечает мок-модули и агрегаты на фикстурах.

1 Валидация проблемы
Нужно понять присущие отдельным продавьцам свойства, отличающиеся в рамках даже одной категории
Важно определить показатели или "свойства" , для показа продавцам, сделать чёткое разделение категорий конкурентов для сбора данных.
Определить наличие категорий, где продавцы уже отслеживают конкурентов
Нужно выбрать, какой срез сделаем в рамках категории конкурентов для предоставления данных, будет это среднее/ лидеры/ сегменты по заработку
2 Оценка потенциала
определим бизнес метрики
Возьмём для оценки эффекта ключевую метрику: активность использования статистики продавцами
Так же надо выбрать метрики для оценки рисков, например активность продавца после первого месяца использования статистики, если она упала, то с какими метриками это может быть связано
Взять метрики для оценки динамики в рамках одной категории конкурентов, не станут ли все слишком похожи для улучшения продаж, как это скажется на продажах.
3 Дизайн теста
Целевые метрики: Использование статистики
Proxy метрики: количество изменений в объявлениях среди использующих статистику, изменение цены объявлений по категориям конкурентов
Контрольные метрики: CES, снижение продаж продавцов, количество жалоб

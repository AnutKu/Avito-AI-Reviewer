Онлайн кинотеатр
Доработка: персональная скидка при продлении подписки
1. Какова цель?
Цель - удержание пользователей в сервисе. С помощью новой доработки планируется уменьшить количество отмененных подписок, что позволит удержать и даже занять часть рынка онлайн кинотеатров в некоторых странах. Доработка закрывает потребность пользователя в получении контента по более низкой цене и будет полезна на момент продления или попытки отмены подписки.
- Региональная скидка позволит удержать часть рынка даже бедных странах
- Персональная скидка позволит удержать лояльных пользователей, либо вернуть старых
Для определения наилучшего применения персональной скидки необходимо провести несколько А/B экспериментов с различной стратегией.
2. Какие метрики позволяют замерить, добились ли вы цели?
В качестве основной метрики можно использовать Retention Rate как показатель удержания пользователя.
3. За счет чего вы добьетесь цели?
При попытке отмены подписки будет предлагаться персональная скидка. Размер и длительность скидки будет определяться в отдельных экспериментах. Также можно ввести скидку "за лояльность", чем дольше пользователь имеет подписку, тем выше для него будет скидка. Для лучшего завлечения можно показывать какая скидка за какой срок будет достигнута.
4. Какие из прокси метрик?
В качестве прокси метрики можно использовать:
- Количество пользователей, отменивших и/или не продливших подписку за месяц
- Увеличение длительности/количества сессий на пользователя (среднее за месяц)
- Количество сессий в месяц
5. Какие контр метрики?
- ARPU или ARPPU, если есть бесплатный пероиод
- Количество подписчиков в месяц
